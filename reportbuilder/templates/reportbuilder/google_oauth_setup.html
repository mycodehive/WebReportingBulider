데이터 연결로 돌아가기

1. Google Cloud 준비

  1. Google Cloud 프로젝트에서 Google Sheets API를 사용 설정합니다.
  2. Google Auth Platform에서 동의 화면을 설정하고 테스트 중이면 사용할 Google 계정을 테스트 사용자로 추가합니다.
  3. OAuth 클라이언트를 웹 애플리케이션으로 생성합니다.
  4. 승인된 리디렉션 URI에 아래 주소를 정확히 등록합니다.

운영에서는 HTTPS 주소를 사용하세요. localhost와 127.0.0.1은 서로 다른 주소입니다.

3. 시트 연결과 인증

데이터 연결에서 Google Sheets → 비공개 / 계정 공유 (OAuth)를 선택해 등록한 뒤, 해당 연결의 Google 인증을 누르세요. 시트를 볼 수 있는 Google 계정으로 승인하고 연결 테스트를 실행합니다.

읽기 전용 Sheets 권한을 요청합니다. 인증해도 해당 Google 계정에 없는 시트 접근 권한이 생기지는 않습니다. 테스트 상태 앱이나 조직 정책에 따라 재인증이 필요할 수 있습니다.
