WEB REPORT DESIGNER / OPEN SOURCE

데이터를 연결하고,
보고서를 완성하다.

업무 데이터를 보고서로 만드는 새로운 방식.

WebReportingBuilder는 Excel·CSV·데이터베이스 데이터를 연결해, 웹 캔버스에서 보고서 양식을 만들고 미리보기·게시·공유·내보내기까지 이어가는 독립형 오픈소스 도구입니다.

↗ DATA CONNECTION⌗ VISUAL EDITOR◫ REPORT PUBLISHING⇄ REUSE & INTEGRATION
01 / CAPABILITIES

하나의 도구로,
보고서의 처음부터 끝까지.

데이터 수집부터 레이아웃 구성, 결과 출력과 기존 시스템 연동까지. 반복되는 보고서 작업에 필요한 핵심 기능을 제공합니다.

↗01

다양한 업무 데이터 연결

Excel·CSV·SQLite·Google Sheets와 지원 DB/API 커넥터로 보고서에 필요한 데이터를 연결합니다.

⌗02

웹 캔버스에서 직접 편집

필드·텍스트·이미지를 끌어 배치하고 크기와 속성을 조정합니다. 실행 취소와 다시 실행으로 편집을 이어갑니다.

∑03

반복 내역과 합계를 한 번에

상세 행 반복, 그룹별 소계, 전체 합계, 머리말·꼬리말과 페이지 번호로 여러 페이지의 업무 보고서를 구성합니다.

⌕04

조건에 맞춰 조회·미리보기

필터·정렬·실행 매개변수를 설정하고 실제 데이터로 결과를 확인한 뒤 게시합니다.

⇩05

필요한 형태로 출력

HTML·XLSX·CSV로 결과를 내려받고, PDF 출력 환경을 갖추면 인쇄용 보고서도 만들 수 있습니다.

◎06

검증한 버전 게시·공유

수정본과 게시본을 구분해 운영하고, 비밀번호와 유효기간을 지정할 수 있는 공유 링크로 결과를 전달합니다.

⇄07

양식 재사용과 서비스 연동

.wrpx 프로젝트를 다른 환경으로 옮겨 데이터 컬럼을 다시 연결하거나 API·iframe으로 기존 서비스와 연동합니다.

◫08

숫자를 이해하기 쉬운 이미지로

막대·선·도넛 차트와 핵심 수치 인포그래픽을 생성해 보고서에 배치합니다. 결과는 생성 시점의 이미지로 저장됩니다.

소개용 콘셉트 이미지 · 실제 제품 화면이 아닙니다.

02 / VISUAL EDITING

머릿속 양식을
화면 위에 그대로.

필드, 텍스트, 이미지를 원하는 곳에 배치하고 크기와 속성을 조정해보세요. 상세 행 반복, 그룹별 소계, 전체 합계, 머리말과 꼬리말을 활용해 복잡한 업무 보고서도 구조화할 수 있습니다.

01드래그 기반 캔버스 배치
02반복 행 · 그룹별 소계 · 전체 합계
03실제 데이터 미리보기와 버전 게시
03 / USE CASES

다양한 업무 속에서
필요한 만큼 활용하세요.

제공 기능을 조합한 활용 예시입니다. 전용 ERP나 매출·정산 시스템 자체를 기본 제공한다는 의미는 아닙니다.

01 / USE CASE

매출·정산 보고서

거래 내역을 부서나 고객 기준으로 정렬하고 소계·총계를 포함한 보고서를 작성합니다.

부서별 업무 현황

↗
03 / USE CASE

반복되는 목록·업무 양식

동일한 형식으로 출력해야 하는 내역서와 업무 목록을 반복 페이지로 구성합니다.

↗
04 / USE CASE

기존 시스템의 보고서 화면

API·iframe으로 업무 시스템에 보고서 실행 화면을 연결하고, 데이터가 다른 환경에서도 양식을 재사용합니다.

↗
04 / REUSE & DELIVERY

한 번 만든 양식,
여러 곳에서 활용.

결과를 공유 링크로 전달하고, HTML·XLSX·CSV 형식으로 내보내세요. 프로젝트 파일(.wrpx)로 양식을 옮기거나 API·iframe 방식으로 기존 업무 서비스에 연결할 수 있습니다.

01비밀번호 · 유효기간 기반 공유 옵션
02프로젝트 내보내기와 컬럼 재연결
03API · iframe 서비스 연동

05 / HOW IT WORKS

세 단계면 충분합니다.

STEP 01 — CONNECT

데이터 연결

파일 또는 지원되는 데이터 소스를 등록합니다.

STEP 02 — DESIGN

보고서 디자인

필드와 요소를 배치하고 출력 양식을 구성합니다.

STEP 03 — DELIVER

결과 확인 · 활용

미리보기 후 게시·공유하거나 필요한 형식으로 내보냅니다.
