## 인포그래픽 사용법 (수치 필드와 문자열 숫자변환)

### 사용자가 보고서에 차트를 넣는 순서

1. `/reports/`에서 수정 권한이 있는 보고서의 **편집** 화면을 엽니다.
2. 왼쪽 **인포그래픽** 탭에서 막대·선·도넛·핵심 수치(합계) 중 하나를 선택하고 제목·단위·강조 색을 설정합니다.
3. **수치 입력 방식**을 선택합니다.
   - **직접 입력**: 한 줄에 `항목,숫자`를 입력합니다. 예: `서울,1200`, `부산,850`. 숫자에는 천 단위 쉼표나 통화기호를 넣지 않습니다.
   - **보고서 데이터셋**: 먼저 데이터 탭에서 본인에게 허용된 연결·테이블을 선택해 데이터셋을 추가하거나 재연결합니다. 인포그래픽 탭에서 데이터셋·항목 필드·수치 필드·집계를 선택합니다.
4. **항목 필드**는 이름을 묶는 기준입니다(예: 부서). **수치 필드**는 합계 또는 평균을 계산할 값입니다(예: 금액).
   - 숫자 타입(`integer`, `decimal`, `number`)은 그대로 사용합니다.
   - CSV 등에서 숫자가 문자열(`string`)로 읽힌 경우 목록에 **문자열 → 숫자변환**으로 표시됩니다. 해당 열을 선택하면 차트 조회에서 숫자로 변환합니다. 원본 연결이나 보고서의 필드 타입·매핑은 변경하지 않습니다.
   - 문자열 열의 실제 값은 `1200`, `12.5`, `-10`처럼 숫자여야 합니다. 이름·문장·`1,200`·`₩1200`·`12%`가 있으면 오류가 표시됩니다. 빈 값은 집계에서 제외하며 0은 포함합니다. 숫자변환이 목록에 표시되어도 그 열이 실제 숫자라는 뜻은 아닙니다.
5. 매개변수가 필요한 보고서는 **보고서 입력값(JSON)**에 이름과 값을 입력합니다. 예: `{"department":"영업"}`. 필요 없으면 `{}`를 유지합니다. 합계는 같은 항목의 값을 더하고 평균은 빈 값을 제외한 행의 평균을 계산합니다.
6. **차트 미리보기**를 누릅니다. 데이터셋 방식은 현재 편집본을 먼저 저장한 뒤 권한·필터·행 정책을 적용해 조회합니다.
7. **캔버스에 추가 → 보고서 저장** 순서로 마칩니다. 이미지를 선택해 위치·크기를 조정하고 보고서 미리보기로 배치를 확인합니다.

### 수치 필드가 안 보이거나 생성에 실패할 때

| 상황 | 확인할 내용 |
| --- | --- |
| 데이터셋 목록이 비어 있음 | 데이터 탭에서 데이터셋을 추가했는지 확인합니다. 프로젝트를 가져왔다면 데이터 연결과 컬럼을 재매핑합니다. |
| 수치 필드 목록이 비어 있음 | 올바른 데이터셋을 선택합니다. 숫자 또는 문자열 필드가 필요합니다. 날짜·불리언·이미지 필드는 수치 목록에서 제외됩니다. |
| 문자열 숫자변환 오류 | 숫자가 있는 열인지 확인하고 원본에서 쉼표·기호·문자 값을 정리합니다. 보고서 재연결 화면의 타입 변환과 차트용 문자열 숫자변환은 별개입니다. |
| 조회 결과에 항목이 없음 | 필터·매개변수·행 정책과 원본 데이터의 빈 수치 값을 확인합니다. |
| 항목이 24개를 초과함 | 데이터셋 필터로 범위를 줄입니다. 같은 항목 이름을 묶은 결과가 1~24개여야 합니다. |
| 도넛 차트 생성 실패 | 음수는 사용할 수 없으며 전체 합계가 양수여야 합니다. |
| 데이터 연결 권한 오류 | 본인 소유 연결과 보고서의 수정 권한을 확인합니다. 일반 사용자는 다른 사용자의 개인 연결을 볼 수 없습니다. |

### 차트 이미지와 갱신

인포그래픽은 생성 시점의 **PNG 이미지**입니다. 보고서를 다시 열거나 출력해도 데이터 변화에 따라 자동 갱신되지 않습니다. 데이터·필터·매개변수가 바뀌면 다시 미리보기와 캔버스 추가를 진행하고 기존 이미지를 삭제한 뒤 저장합니다. 보고서 미리보기·게시·프로젝트 내보내기에 본문 이미지로 포함됩니다. 라이트·다크 모드는 편집 화면에 적용되며 차트 이미지 자체는 흰색 배경으로 생성됩니다.

핵심 수치 차트는 선택한 집계 결과의 합계입니다. 항목별 평균을 선택한 뒤 핵심 수치를 만들면 **항목 평균의 합계**가 표시되므로 전체 행 평균으로 해석하지 마세요.
