# 웹 레포트 빌더 사용 매뉴얼

**데이터를 연결하고 → 필드를 배치하고 → 미리보기로 확인한 뒤 → 게시하거나 내보내면 됩니다.**

## 회원가입과 메일 인증

회원가입 후 입력한 메일로 받은 인증 링크를 열고 **메일 인증 완료**를 눌러 주세요. 신규 가입자는 인증을 완료해야 보고서 등 서비스를 이용할 수 있습니다. 링크는 24시간 동안 유효하며, 재발송하면 이전 링크는 무효화됩니다.

메일이 오지 않으면 스팸함을 확인하고 로그인 후 인증 안내 화면(`/accounts/email/`)에서 **인증 메일 다시 보내기**를 누르세요. 재발송은 60초 간격, 시간당 5회까지 가능합니다. 기존 사용자는 관리자에게 인증 메일 발송을 요청할 수 있습니다.

## 1. 예제로 먼저 익히기

회원가입 또는 관리자 화면의 사용자 생성이 완료되면 보고서 라이브러리(`/reports/`)에 **매출 현황 예제**가 자동으로 준비됩니다.

1. 로그인하고 보고서 라이브러리를 엽니다.
2. 예제의 **디자인**을 누릅니다.
3. 제목을 선택해 오른쪽 속성에서 내용을 바꿉니다.
4. **미리보기**를 누릅니다.
5. 합성 데이터 65행과 자동으로 생성된 여러 페이지를 확인합니다.

실제 업무정보를 포함하지 않는 예제이므로 편하게 수정할 수 있습니다.

## 2. 내 데이터 등록하기

데이터 연결은 각 사용자가 직접 등록·수정·삭제합니다. 데이터 연결 메뉴와 연결 목록 API에는 본인이 등록한 연결만 표시되며, 다른 사용자의 연결 설정·파일·인증 정보에 접근할 수 없습니다. 관리자는 별도 관리자 콘솔에서 운영 관리를 수행합니다.

### Excel 또는 CSV

1. **데이터 연결**에서 연결 이름을 입력합니다.
2. 자료원을 Excel 또는 CSV로 선택합니다.
3. 파일을 선택하고 연결을 등록합니다.
4. 목록의 **연결 테스트**로 읽기 가능 여부를 확인합니다.

표의 첫 행에는 컬럼 제목을 넣으면 좋습니다. CSV 예:

```csv
customer,department,amount
홍길동,영업팀,120000
김영희,기획팀,250000
```

Excel은 `.xlsx/.xlsm`, CSV는 `.csv/.tsv`를 기본 지원합니다. Excel 매크로는 실행하지 않고 수식은 파일에 저장된 계산 결과를 읽습니다. 서버가 사용자의 원본 Excel을 직접 재계산하지 않습니다.

### 데이터베이스

자료원을 선택하면 연결 설정 예시가 나타납니다. host, port, database 또는 service_name, username, password를 실제 값으로 입력합니다. 읽기 전용 계정을 사용하세요.

Oracle/MSSQL/MariaDB는 별도 드라이버 설치와 네트워크 접근이 필요합니다. 연결 성공 후에도 보고서용 테이블/뷰의 조회 권한이 있어야 합니다.

### Google Sheets

spreadsheet ID, 탭 이름, 헤더 행을 지정합니다. 서비스 계정 JSON을 입력하고 대상 파일에 그 계정을 공유하거나, 유효한 OAuth `access_token`을 입력합니다. 토큰이 만료되면 다시 연결해야 합니다.

### Access

MDBTools로 읽을 수 있는 `.mdb/.accdb`의 기본 로컬 테이블만 사용합니다. 암호화·링크 테이블·VBA·폼·Access 보고서·복합 필드는 자동 실행하지 않습니다. 읽을 수 없는 파일은 Excel/CSV로 변환해서 연결하세요.

## 3. 보고서 만들기

1. 보고서 라이브러리에서 **새 보고서**를 누릅니다.
2. 이름을 입력하고 디자이너를 엽니다.
3. 왼쪽에서 데이터 연결과 테이블/시트를 선택합니다.
4. **데이터셋 추가**를 누릅니다.
5. 필드 목록에서 원하는 컬럼을 클릭하거나 캔버스로 끌어 놓습니다.

‘데이터셋’은 보고서에서 사용하는 논리적인 표입니다. 실제 DB 컬럼명 대신 안정적인 논리 필드 ID를 사용하므로 다른 DB로 재연결해도 디자인을 유지할 수 있습니다.

## 4. 고정 페이지와 반복 페이지

| 페이지 | 용도 |
|---|---|
| 고정 페이지 | 표지, 안내문, 개별 양식, 전체 합계 |
| 반복(Flow) 페이지 | 여러 행의 목록, 상세 내역, 그룹별 보고서 |

고정 페이지에 여러 행의 필드를 넣으면 단일값·첫 행·합계 등 값을 어떻게 표시할지 선택합니다. 임의로 첫 값을 선택하지 않습니다. 첫 행을 사용할 때는 정렬을 지정하세요.

여러 행을 출력하려면 페이지를 **Flow**로 바꾸고 Detail 영역에 필드를 배치합니다. Detail에 배치한 한 줄이 데이터 행마다 반복됩니다.

### 밴드란?

반복 페이지에서 출력 역할이 정해진 영역입니다.

| 밴드 | 의미 |
|---|---|
| ReportHeader | 보고서 제목, 한 번 출력 |
| PageHeader | 각 페이지의 컬럼명/머리말 |
| Detail | 데이터 행마다 반복 |
| GroupHeader/GroupFooter | 그룹명/소계 |
| ReportFooter | 마지막 전체 합계 |
| PageFooter | 각 페이지의 번호/꼬리말 |

그룹 밴드를 사용할 때는 그룹 필드로 먼저 정렬해 같은 값이 연속해서 오도록 하세요. 현재 중첩 그룹은 지원하지 않습니다.

## 5. 텍스트·이미지·위치 편집

- 도구함에서 텍스트, 이미지, 선, 사각형, 페이지 번호 등을 추가합니다.
- 요소를 끌어 이동하고 크기 조절점을 사용해 크기를 바꿉니다.
- 오른쪽 속성에서 좌표·너비·높이·글자 크기·색·정렬을 입력할 수 있습니다.
- 위치와 크기는 mm 기준입니다. 화면 확대율을 바꿔도 저장된 위치는 바뀌지 않습니다.
- 이미지는 업로드 후 사용합니다. 프로젝트 내보내기에 함께 포함됩니다.
- undo/redo로 직전 변경을 되돌리거나 다시 적용합니다.
- 레이어 순서를 조절하면 겹친 요소의 앞/뒤 위치가 바뀝니다.

긴 텍스트는 고정 높이로 자르거나 grow로 높이를 늘릴 수 있습니다. 현재 grow는 보수적인 높이 추정이며 한 페이지보다 큰 단일 밴드는 오류를 표시합니다. 중요한 양식은 미리보기와 실제 서버 PDF를 확인하세요.

## 6. 페이지 추가·넘김

페이지 목록에서 추가·복제·삭제·선택합니다. 표지와 본문을 별도 템플릿으로 만들 수 있습니다.

**디자인 페이지 수와 출력 페이지 수는 다릅니다.** 반복 템플릿 한 페이지가 데이터에 따라 여러 출력 페이지로 늘어납니다.

페이지 나누기 요소 또는 밴드의 강제 페이지 넘김을 사용하면 특정 영역부터 새 페이지로 출력합니다. 페이지 번호와 전체 페이지 수는 실제 출력 결과에 맞춰 표시됩니다.

## 7. 필터·정렬·매개변수

**필터 · 정렬 · 매개변수**에서 조건을 설정합니다.

- 필터: 부서가 영업팀인 행만 출력하는 등의 조건.
- 정렬: 부서 → 고객명 순서처럼 여러 기준 지정.
- 매개변수: 실행할 때 입력할 기준일·검색어·금액 등.

매개변수를 만든 뒤 필터의 값 대신 그 매개변수를 선택하면 실행 화면에서 입력받습니다. 필수 입력이나 잘못된 날짜/숫자는 서버에서 검사합니다.

CSV에서 금액이 문자열로 분석된 경우 숫자 합계가 되지 않을 수 있습니다. **재연결**에서 대상 컬럼과 `to_decimal` 변환을 선택하고 논리 타입도 decimal 또는 number로 지정하세요. 문자열 식별번호는 앞자리 0 보존을 위해 숫자로 바꾸지 않는 편이 좋습니다.

## 8. 저장·미리보기·게시

| 기능 | 결과 |
|---|---|
| 저장 | 수정본을 버전으로 저장 |
| 미리보기 | 실제 데이터와 현재 디자인으로 페이지 생성 |
| 게시 | 검증한 특정 버전을 실행 URL에 연결 |
| 게시 해제 | 운영 실행 중지, 디자인 유지 |

게시 후 수정본을 저장해도 기존 게시 버전은 바로 바뀌지 않습니다. 새 버전을 게시해야 운영 화면이 바뀝니다. 같은 보고서의 이전 revision으로 게시를 바꾸면 rollback할 수 있습니다.

다른 탭에서 변경했으면 저장 충돌 메시지를 표시합니다. 먼저 새로고침해서 최신 내용을 확인하고 덮어쓰지 않도록 하세요. 실시간 공동편집은 아직 제공하지 않습니다.

## 9. 다운로드 종류

| 파일 | 용도 |
|---|---|
| PDF | 페이지 양식과 인쇄. 서버 Chromium 설치 필요 |
| HTML | 실행 시점 보고서 결과. DB 자동 갱신 없음 |
| XLSX | 데이터셋별 데이터 표. 자유배치 모양을 그대로 복제하지 않음 |
| CSV | 평면 데이터, 여러 데이터셋이면 ZIP |
| `.wrpx` | 편집 가능한 디자인·논리 계약·이미지를 다른 환경으로 이동 |

실행 화면에서 한 번 조회한 뒤 PDF/XLSX/CSV를 누르면 같은 실행 스냅샷을 사용합니다. DB가 중간에 바뀌어도 해당 실행의 결과는 유지됩니다. 기본 다운로드 보존 기한은 24시간이며 권한/정책이 바뀌면 다시 실행해야 합니다.

## 10. 다른 사이트의 DB로 재사용

1. 원래 서비스에서 **프로젝트 내보내기**로 `.wrpx`를 받습니다.
2. 대상 서비스에 같은 버전 또는 호환 런타임을 설치합니다.
3. 대상 서비스에서 프로젝트를 가져옵니다.
4. 대상 DB/Excel/Sheets 연결을 등록합니다.
5. 디자이너 왼쪽에서 새 연결과 테이블을 선택합니다.
6. **재연결**을 눌러 기존 논리 필드를 대상 컬럼에 매핑합니다.
7. 타입이 다르면 명시 변환을 선택합니다.
8. 저장 → 미리보기 → 게시합니다.

예: 원래 `고객명`이 MariaDB의 `customer_name`이었다면, 새 Oracle의 `BUYER_NAME`에 연결해 같은 디자인을 사용할 수 있습니다.

프로젝트에는 비밀번호·토큰·원본 데이터 파일·원본 사용자 권한을 포함하지 않습니다. 대상 DB에 필요한 의미의 컬럼이 없으면 VIEW나 데이터 어댑터를 마련해야 합니다. 파일 하나만으로 임의 사이트가 DB를 자동 실행하는 것은 아니며 호환 런타임이 필요합니다.

## 11. 사용자 공유와 권한

관리 화면에서 사용자를 그룹에 넣고 보고서의 `viewer_groups`, 데이터 연결의 `groups`를 모두 지정합니다. 보고서 보기 권한만 있으면 원본 데이터 연결 권한이 자동 생기지 않습니다.

연결의 허용 객체·컬럼, 행 정책, 마스킹을 관리자가 지정할 수 있습니다. 행 정책은 보고서 필터에 AND로 적용되어 작성자가 우회할 수 없습니다. 현재 마스킹 필드를 조건/정렬/집계에 사용하는 것은 차단합니다.

## 12. 오류 해결

| 메시지 | 해결 |
|---|---|
| 데이터셋 연결/매핑 필요 | 재연결에서 연결·컬럼 지정 |
| 물리·논리 타입 불일치 | 명시 타입 변환 선택 |
| 원본 조회 한도 초과 | VIEW/시트/파일 자체 범위를 줄이기 |
| 필수 매개변수 누락 | 실행 입력값 채우기 |
| 요소가 페이지 영역 초과 | 위치·크기·밴드 높이 수정 |
| Grouping requires contiguous… | 그룹 필드로 먼저 정렬 |
| PDF renderer unavailable | 설치 담당자에게 Chromium 확인 요청 |
| 수정/연결 권한 없음 | 보고서와 데이터 연결의 그룹 권한 확인 |

현재 지원하지 않는 기능과 실제 연결 검증 상태는 `docs/SUPPORT_MATRIX.md`에 정리되어 있습니다.

## 출력·공유 시 알아둘 점

XLSX는 데이터 표이며 PDF의 인쇄 배치를 복제하지 않습니다. Decimal 금액과 날짜는 문자열 셀로 보존됩니다. `.wrpx`에는 연결 비밀번호·원본 파일·실행 데이터가 자동 포함되지 않지만, 직접 입력한 텍스트/필터 값은 남으므로 공개 전 확인하세요.

## 예제 보고서 다시 만들기

터미널에서 프로젝트 폴더로 이동해 아래 명령을 실행합니다.

```powershell
uv run python manage.py seed_demo --reset
```

기존 `매출 현황 예제`를 삭제한 뒤 합성 CSV와 보고서를 새로 만듭니다. 해당 예제의 연결을 다른 보고서에서도 사용 중이면 연결 파일은 삭제하지 않습니다. 예제 외의 보고서 데이터는 초기화하지 않습니다.

## 넓은 작업 화면과 접속 통계

디자인 화면의 **전체화면** 버튼으로 작업 영역을 넓힙니다. 상단에서 좌측 메뉴를 접고, 라이트·다크 모드를 바꿀 수 있습니다. 설정은 현재 브라우저에 저장되며 보고서 출력 색상은 유지됩니다.

라이브러리 카드의 **통계** 버튼은 소유자와 관리자에게 제공됩니다. 팝업에서 기간·접속 유형·국가·기기·브라우저 조건과 일별 추이를 확인하고 Excel/PDF로 내려받으세요. 접속 수는 화면 열기·게시본 실행·임베드 실행 이벤트 수이며 고유 방문자 수가 아닙니다.

국가 정보는 서버에 GeoIP 국가 DB를 설정해야 합니다. 로컬 접속은 Private, DB 미설정은 Unknown으로 기록됩니다. 원본 IP/User-Agent는 통계 DB에 보관하지 않습니다. PDF는 Chromium 설치가 필요합니다. 상세 설치·기록 기준은 저장소의 `docs/WORKSPACE_AND_ANALYTICS.md`를 참고하세요.


### Demo 자동 준비
회원가입하거나 관리자가 새 활성 사용자를 등록하면 해당 사용자 전용 합성 매출 데모와 데이터 연결을 생성합니다. 생성에 실패해도 계정 등록은 완료되며, 사용자는 `/reports/`에서 자동 재시도하거나 “다시 시도” 버튼을 누를 수 있습니다. 자동 생성 완료 후에는 보고서 이름을 바꾸거나 삭제해도 자동으로 다시 만들지 않습니다.

관리자가 기존 사용자에게 데모를 강제로 생성하려면 `/admin/auth/user/`에서 대상 사용자를 체크하고 **작업 → 데모 보고서 생성 / 재생성 → 실행**을 선택합니다. 선택한 활성 사용자별로 기존 “매출 현황 예제”만 재생성하며 직접 작성한 다른 보고서는 유지합니다. 한 사용자가 실패해도 나머지 사용자 처리는 계속되고 성공·실패·비활성 제외 결과가 표시됩니다. 실패한 사용자는 다시 선택해 재실행하세요.


### 공개 공유 링크
공유 링크 생성 시 **공유 비밀번호**에 8~128자를 입력하면 방문자가 비밀번호를 확인해야 보고서를 볼 수 있습니다. 비우면 기존처럼 링크만으로 열립니다. 비밀번호는 해시로 저장하며 관리 목록에는 보호 여부만 표시합니다. 비밀번호를 바꾸려면 기존 링크를 해제하고 새 비밀번호로 링크를 생성하세요.

게시된 활성 보고서 카드에서 **공유**를 누릅니다. 소유자와 관리자가 링크를 생성할 수 있습니다. 기간 제한 없음 또는 한국 시간 기준 시작·종료 시각을 선택하고, 필요한 보고서 입력값을 지정한 뒤 **공유 링크 생성 → 링크 복사**를 누르세요. 링크 원문은 생성 직후 한 번 표시하므로 보관하세요.

링크를 가진 누구나 로그인 없이 보고서를 봅니다. 매번 게시본의 데이터를 보고서 소유자 권한으로 조회하며, 입력값은 링크 생성 시 지정한 값으로 고정됩니다. 공유 해제, 보고서 중지, 게시 중지, 다른 버전 게시, 소유자 비활성화 시 접근을 차단합니다. 기간이 있으면 시작 시각 이상·종료 시각 미만에서만 열립니다. 만료는 새로운 요청을 차단하며 이미 열었거나 저장한 내용을 회수하지 않습니다.

링크 관리 목록의 **공유 해제**는 즉시 적용됩니다. 새 버전을 공유하려면 새 링크를 만드세요. 공유 접속은 조회 통계에 포함됩니다. 업데이트 후 `uv run python manage.py migrate`가 필요합니다.

### 보고서 대표 이미지
라이브러리의 각 보고서 카드에서 **대표 이미지**를 열어 10MB 이하 PNG, JPEG, GIF, WebP 파일을 등록합니다. 저장 후 카드에 표시되며 새 파일로 교체하거나 **대표 이미지 제거**로 기본 아이콘으로 돌아갈 수 있습니다. 소유자와 관리자만 변경할 수 있습니다. 대표 이미지는 라이브러리용이며 보고서 본문 이미지와 별개입니다.

## 인포그래픽 사용법 (수치 필드와 문자열 숫자변환)

### 사용자가 보고서에 차트를 넣는 순서

1. `/reports/`에서 수정 권한이 있는 보고서의 **편집** 화면을 엽니다.
2. 왼쪽 **인포그래픽** 탭에서 막대·선·도넛·핵심 수치(합계) 중 하나를 선택하고 제목·단위·강조 색을 설정합니다.
3. **수치 입력 방식**을 선택합니다.
   - **직접 입력**: 한 줄에 `항목,숫자`를 입력합니다. 예: `서울,1200`, `부산,850`. 숫자에는 천 단위 쉼표나 통화기호를 넣지 않습니다.
   - **보고서 데이터셋**: 먼저 데이터 탭에서 본인에게 허용된 연결·테이블을 선택해 데이터셋을 추가하거나 재연결합니다. 인포그래픽 탭에서 데이터셋·항목 필드·수치 필드·집계를 선택합니다.
4. **항목 필드**는 이름을 묶는 기준입니다(예: 부서). **수치 필드**는 합계 또는 평균을 계산할 값입니다(예: 금액).
   - 숫자 타입(`integer`, `decimal`, `number`)은 그대로 사용합니다.
   - CSV 등에서 숫자가 문자열(`string`)로 읽힌 경우 목록에 **문자열 → 숫자변환**으로 표시됩니다. 해당 열을 선택하면 차트 조회에서 숫자로 변환합니다. 원본 연결이나 보고서의 필드 타입·매핑은 변경하지 않습니다.
   - 문자열 열의 실제 값은 `1200`, `12.5`, `-10`처럼 숫자여야 합니다. 이름·문장·`1,200`·`₩1200`·`12%`가 있으면 오류가 표시됩니다. 빈 값은 집계에서 제외하며 0은 포함합니다. 숫자변환이 목록에 표시되어도 그 열이 실제 숫자라는 뜻은 아닙니다.
5. 매개변수가 필요한 보고서는 **보고서 입력값(JSON)**에 이름과 값을 입력합니다. 예: `{"department":"영업"}`. 필요 없으면 `{}`를 유지합니다. 합계는 같은 항목의 값을 더하고 평균은 빈 값을 제외한 행의 평균을 계산합니다.
6. **차트 미리보기**를 누릅니다. 데이터셋 방식은 현재 편집본을 먼저 저장한 뒤 권한·필터·행 정책을 적용해 조회합니다.
7. **캔버스에 추가 → 보고서 저장** 순서로 마칩니다. 이미지를 선택해 위치·크기를 조정하고 보고서 미리보기로 배치를 확인합니다.

### 수치 필드가 안 보이거나 생성에 실패할 때

| 상황 | 확인할 내용 |
| --- | --- |
| 데이터셋 목록이 비어 있음 | 데이터 탭에서 데이터셋을 추가했는지 확인합니다. 프로젝트를 가져왔다면 데이터 연결과 컬럼을 재매핑합니다. |
| 수치 필드 목록이 비어 있음 | 올바른 데이터셋을 선택합니다. 숫자 또는 문자열 필드가 필요합니다. 날짜·불리언·이미지 필드는 수치 목록에서 제외됩니다. |
| 문자열 숫자변환 오류 | 숫자가 있는 열인지 확인하고 원본에서 쉼표·기호·문자 값을 정리합니다. 보고서 재연결 화면의 타입 변환과 차트용 문자열 숫자변환은 별개입니다. |
| 조회 결과에 항목이 없음 | 필터·매개변수·행 정책과 원본 데이터의 빈 수치 값을 확인합니다. |
| 항목이 24개를 초과함 | 데이터셋 필터로 범위를 줄입니다. 같은 항목 이름을 묶은 결과가 1~24개여야 합니다. |
| 도넛 차트 생성 실패 | 음수는 사용할 수 없으며 전체 합계가 양수여야 합니다. |
| 데이터 연결 권한 오류 | 본인 소유 연결과 보고서의 수정 권한을 확인합니다. 일반 사용자는 다른 사용자의 개인 연결을 볼 수 없습니다. |

### 차트 이미지와 갱신

인포그래픽은 생성 시점의 **PNG 이미지**입니다. 보고서를 다시 열거나 출력해도 데이터 변화에 따라 자동 갱신되지 않습니다. 데이터·필터·매개변수가 바뀌면 다시 미리보기와 캔버스 추가를 진행하고 기존 이미지를 삭제한 뒤 저장합니다. 보고서 미리보기·게시·프로젝트 내보내기에 본문 이미지로 포함됩니다. 라이트·다크 모드는 편집 화면에 적용되며 차트 이미지 자체는 흰색 배경으로 생성됩니다.

핵심 수치 차트는 선택한 집계 결과의 합계입니다. 항목별 평균을 선택한 뒤 핵심 수치를 만들면 **항목 평균의 합계**가 표시되므로 전체 행 평균으로 해석하지 마세요.


### Google Sheets 공개 연결과 OAuth
데이터 연결에서 Google Sheets를 선택하고 공개 링크 또는 비공개 / 계정 공유 (OAuth)를 지정합니다. 비공개 시트는 별도 Google OAuth 설정 화면에서 Client ID·Secret을 등록한 후 연결 목록에서 Google 인증을 진행하세요. 자세한 발급·연결 절차는 [Google Sheets 가이드](GOOGLE_SHEETS.md)를 참고하세요.

### 게시판 글·답변 편집

게시글과 답변 / 댓글에는 Summernote 편집기가 적용됩니다. 도구 모음에서 굵게·기울임·목록·정렬·링크·표와 Picture·Video·Code View 기능을 사용할 수 있으며 라이트 / 다크 모드에 맞춰 표시됩니다. Picture는 HTTPS 이미지 주소 또는 64KB 이하 PNG/JPEG/GIF/WebP 파일을 지원합니다. 큰 이미지는 HTTPS 주소로 등록하세요. Video는 YouTube·Vimeo 주소를 지원합니다. Code View에서는 HTML을 편집할 수 있으며 편집 화면 전환과 저장 시 위험한 HTML이 제거됩니다. 붙여넣기는 일반 텍스트로 처리하므로 서식은 도구 모음에서 적용하세요. 편집기를 불러오지 못하면 일반 입력란에서 작성할 수 있습니다.

### 데이터 연결 수정·삭제
`/connections/`의 **수정**을 열어 연결 이름과 설정 JSON을 바꿀 수 있습니다. 비밀 정보는 암호화된 채 저장되며 화면에 원문을 표시하지 않습니다. 비밀값을 바꾸려면 JSON으로 입력하고, 비워 두면 기존 값을 유지합니다. 파일 연결은 선택적으로 새 파일로 교체할 수 있습니다. 저장 후 연결 테스트를 다시 진행하세요.

**삭제**는 해당 연결을 사용하는 보고서의 데이터 매핑을 끊습니다. 삭제 확인창에서 영향을 확인하고, 이후 보고서 편집 화면에서 새 연결을 매핑하세요. 수정과 삭제는 연결을 만든 관리자 계정에서 할 수 있습니다.
