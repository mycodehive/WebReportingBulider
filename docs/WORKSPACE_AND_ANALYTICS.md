# 넓은 작업 화면과 보고서 접속 통계

## 1. 전체화면으로 디자인하기

보고서의 **디자인** 화면에서 **전체화면** 버튼을 누릅니다. 캔버스와 데이터·속성 패널이 화면을 채우고 저장·미리보기 등의 작업 버튼도 함께 표시됩니다. 같은 버튼으로 원래 화면으로 돌아옵니다. 브라우저가 전체화면 API를 지원하지 않거나 허용하지 않으면 브라우저 창 안에서 작업 영역을 확대합니다.

미리보기·재연결·조회 설정 팝업은 전체화면에서도 사용할 수 있습니다. 브라우저의 기본 전체화면은 Esc로 나갈 수 있습니다.

## 2. 좌측 메뉴 접기

상단의 메뉴 버튼으로 전체 서비스의 좌측 메뉴를 접고 펼칩니다. 설정은 사용 중인 브라우저에 저장됩니다. 디자이너의 데이터·속성 패널은 별도 작업 도구이므로 이 버튼은 전역 메뉴에 적용됩니다.

## 3. 라이트·다크 모드

상단의 테마 버튼으로 라이트/다크 모드를 변경합니다. 처음 방문할 때는 운영체제의 테마를 따르고, 직접 선택한 이후에는 같은 브라우저에서 선택을 유지합니다.

입력창, 선택 목록, 버튼, 표, 도움말, 레이어 팝업도 함께 바뀝니다. 보고서의 흰 용지와 작성한 텍스트·이미지 색은 출력 결과와 일치하도록 유지됩니다. 테마를 바꿔도 PDF/보고서 디자인의 색이 바뀌지는 않습니다.

## 4. 통계 팝업 열기

`/reports/`의 보고서 카드에서 **통계**를 누릅니다. 보고서 소유자와 관리자가 조회할 수 있으며, 실행 공유 권한만 있는 사용자는 통계를 조회할 수 없습니다.

- 기본 기간은 오늘을 포함한 최근 30일입니다. 날짜와 접속 시간은 한국 시간(Asia/Seoul)을 기준으로 표시합니다.
- 기간과 이벤트·국가·기기·브라우저 조건을 적용할 수 있습니다.
- 접속 이벤트 수, 화면 열기·게시본 실행·임베드 실행, 일별 추이와 국가·기기·브라우저 분포, 최근 접속 내역을 확인합니다.
- **Excel 다운로드**와 **PDF 다운로드**는 적용한 조회 조건을 사용합니다. 결과가 큰 경우 상세 행 표시/다운로드 제한과 생략 수를 확인하세요. 전체 집계와 제한된 상세 내역은 구분해서 표시합니다.

접속 이벤트 수는 방문한 사람 수가 아닙니다. 같은 사용자가 화면을 열고 게시본을 실행하면 `view`와 `execute` 이벤트가 각각 기록됩니다. 고유 방문자 추적 쿠키를 만들지 않습니다.

## 5. 어떤 접속을 기록하나요?

| 유형 | 기록 시점 |
|---|---|
| 화면 열기 (`view`) | 권한 확인을 통과한 보고서 뷰어/게시 URL의 GET 응답 |
| 게시본 실행 (`execute`) | 게시된 보고서 실행 API가 성공했을 때 |
| 외부 임베드 (`embed`) | 서명 토큰 검증과 게시본 실행이 성공했을 때 |

디자인 화면, 편집본 미리보기, 실패한 실행, 통계 조회, 다운로드는 접속 통계에서 제외합니다. 이 기능 설치 이전 접속은 소급 생성하지 않습니다.

서버 API로 실행하면 요청한 서버의 접속 환경이 집계됩니다. 실제 브라우저에서 임베드하면 브라우저의 요청 환경이 집계됩니다. 기기·브라우저·OS 정보는 User-Agent 기반 분류이므로 조작되거나 정확하지 않을 수 있습니다.

## 6. 국가 정보 설정

국가는 접속 IP를 로컬 GeoIP 국가 데이터베이스에서 조회합니다. 외부 위치 조회 서비스로 IP를 전송하지 않습니다. 조회 DB 미설정·매핑 실패는 `Unknown`, 사설/로컬 IP는 `Private`으로 저장합니다. VPN이나 프록시를 쓰면 실제 사람의 위치와 다를 수 있습니다.

```powershell
uv sync --frozen --group dev --extra geoip --extra pdf
```

서버 관리자가 MaxMind GeoLite2 Country/GeoIP2 Country 형식의 `.mmdb`를 준비하고 `.env`에 실제 파일 경로를 설정합니다. 데이터베이스는 저장소에 동봉하지 않습니다.

```dotenv
REPORT_ANALYTICS_ENABLED=true
REPORT_GEOIP_DATABASE=C:/geoip/GeoLite2-Country.mmdb
REPORT_TRUSTED_PROXIES=
```

Linux 경로 예시는 `/var/lib/GeoIP/GeoLite2-Country.mmdb`입니다. PDF는 별도로 `uv run playwright install chromium` 및 해당 OS의 시스템 의존성을 준비해야 합니다. 이미 사용하는 DB 커넥터 extra도 `uv sync`에 함께 지정하세요.

프록시 뒤에서 운영할 때 `REPORT_TRUSTED_PROXIES`에 실제 프록시의 IP/CIDR만 지정해야 `X-Forwarded-For`를 신뢰합니다. 프록시는 클라이언트가 전달한 헤더를 올바르게 제거/추가해야 합니다. 설정하지 않으면 서버가 직접 확인한 원격 주소를 사용합니다. 임의의 국가 헤더를 신뢰하지 않습니다.

공식 참고: [MaxMind 로컬 데이터베이스 조회](https://dev.maxmind.com/geoip/geolocate-an-ip/databases/), [GeoIP2 Python API](https://geoip2.readthedocs.io/).

## 7. 저장 항목과 정리

통계에는 보고서 ID, 접속 시간, 이벤트 유형, 국가 코드, 기기·브라우저·OS 분류를 저장합니다. 원본 IP, 원본 User-Agent, 사용자명, URL 쿼리, 보고서 내용은 통계 테이블에 저장하지 않습니다. 시간은 DB에 UTC로 저장하고 화면에서 한국 시간(Asia/Seoul)으로 표시합니다.

1년보다 오래된 접속 통계 정리:

```powershell
uv run python manage.py purge_report_access --days 365
```

이 명령을 서버 스케줄러에서 주기적으로 실행하면 됩니다. 자동 스케줄은 설치 담당자가 설정합니다. `REPORT_ANALYTICS_ENABLED=false`는 새 기록만 중단하며 기존 기록은 유지합니다.

## 8. 업데이트 후 실행

변경 사항이 포함된 브랜치 또는 병합된 main을 받은 뒤 다음을 실행합니다.

```powershell
uv sync --frozen --group dev
uv run python manage.py migrate
uv run python manage.py runserver
```

접속 통계 테이블을 추가하는 마이그레이션이 필요합니다. 운영은 `collectstatic --noinput` 후 프로세스를 재시작합니다. UI가 이전처럼 보이면 브라우저에서 Ctrl+F5로 다시 불러옵니다.
