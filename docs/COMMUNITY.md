# 회사 로고와 게시판

업데이트 후 `uv sync --frozen`과 `uv run python manage.py migrate`를 실행합니다.

## 회사 로고

전체 관리자는 좌측 **환경설정 → 기본정보 → 회사로고** 메뉴에서 회사명과 로고를 등록·교체·삭제합니다.
권장 크기는 투명 PNG 480 × 120px, 최대 2MB입니다. JPG/GIF/WebP도 사용할 수 있고
서버에서 PNG로 변환합니다. 로그인 좌측 상단과 로그인 후 `.brand`에 원본 비율로 표시합니다.
로고 전용 공개 주소는 로고만 제공하며 보고서의 비공개 이미지와 분리되어 있습니다.

## 게시판과 역할

좌측 **게시판** 메뉴에서 전체 관리자가 게시판을 만들 수 있습니다.
리스트형, 카드형, 질문답변형을 선택하고 설명, 사용 여부, 사용자 글쓰기 허용,
담당 관리자와 운영자를 설정합니다.

- 전체 관리자(`is_staff`): 모든 게시판 생성·설정·운영
- 게시판 관리자: 담당 게시판 설정·삭제, 카테고리·상태·역할 관리, 글·답변 관리
- 운영자: 담당 게시판 글·답변·처리 상태 관리 (설정·게시판 삭제 제외)
- 사용자: 공개 게시판 열람, 허용된 게시판에 글쓰기, 자기 글·댓글 수정·삭제

질문답변형은 작성자와 담당 관리자·운영자만 목록·검색·상세·답변에 접근합니다.
게시판별 글 수에도 동일한 제한을 적용합니다. 질문이 있는 1:1 게시판을 공개 유형으로
변경할 수 없습니다. 사용 중지된 게시판은 담당 관리자·운영자에게만 표시합니다.

카테고리는 모든 유형에서 사용합니다. 질문 상태는 접수(파랑), 보류(황갈색), 완료(초록)로
시작하며 이름·색상·순서를 자유롭게 변경하거나 추가·삭제할 수 있습니다.
첫 번째 상태가 새 질문의 기본값입니다. 사용 중인 상태를 삭제하면 해당 질문을 첫 번째
남은 상태로 이동합니다. 카테고리를 삭제하면 글은 분류 없음으로 남습니다.

검색, 카테고리·상태 필터, 20개 단위 페이지 나누기, 관리자·운영자 글 고정,
작성자 후속 댓글, 답변 수정·삭제, 삭제 확인 화면을 제공합니다.

## 편집기

글과 답변은 로컬 정적 파일로 제공하는 Summernote **0.9.1 Lite**를 사용합니다.
라이트/다크 모드와 모바일에서 도구 모음·팝업·코드 입력 영역을 함께 테마 처리합니다.
편집기를 불러올 수 없으면 일반 입력란으로 작성할 수 있습니다.

표·목록·링크·강조와 Picture, Video, Code View 버튼을 제공합니다.
세 버튼의 `aria-label`은 각각 `Picture`, `Video`, `Code View`입니다.
이미지는 HTTPS 주소 또는 64KB 이하 PNG/JPEG/GIF/WebP 파일을 사용합니다.
파일은 본문에 인라인으로 저장하며 기존 본문 최대 길이 제한을 따릅니다.
동영상은 YouTube·Vimeo 임베드만 허용하고 iframe sandbox를 적용합니다.
다른 파일 첨부·임의 iframe·스크립트·폼은 지원하지 않습니다.

붙여넣기는 일반 텍스트로 처리합니다. Code View에서 편집 화면으로 돌아오거나
저장할 때 DOMPurify를 적용하며, 서버는 Bleach와 이미지/임베드 검증으로
HTML·링크·스타일을 다시 정제합니다. 허용되지 않은 HTML은 제거됩니다.

## 환경설정 메뉴 구조

좌측 환경설정(`/settings/`)에서는 콘텐츠 영역 상단의 중메뉴 탭과 탭별 소메뉴로 이동합니다.

| 중메뉴 탭 | 소메뉴 | 기능 |
| --- | --- | --- |
| 기본정보 | 회사로고 | 회사명 및 로고 등록·수정·삭제 |
| 사이트관리 | 메뉴관리 | 좌측 메뉴 추가·수정·삭제 및 순서·접근 대상 관리 |

전체 관리자만 이용할 수 있습니다. 기존 `/settings/company/`, `/menu-management/` 주소도 동일한 환경설정 구조를 표시합니다.
새 중메뉴와 소메뉴는 `reportbuilder/settings_navigation.py`의 `SETTINGS_SECTIONS`에 등록하고 해당 화면에 공통 내비게이션을 포함합니다.
배포 시 `python manage.py migrate`로 기존 회사로고·메뉴관리 좌측 메뉴를 환경설정 메뉴로 통합합니다.
