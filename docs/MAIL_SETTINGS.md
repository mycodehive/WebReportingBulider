# 관리자 메일 설정

환경설정 → 기본정보 → 메일(`/settings/mail/`)에서 사이트 공통 메일 발송 설정을 관리합니다. 일반 사용자는 메뉴가 표시되지 않으며, 직접 GET/POST 접근도 금지됩니다. 메뉴관리에서 관리자 전용 체크를 해제해도 메일 페이지는 공개되지 않습니다.

## 설정

메일러를 선택하면 해당 설정 항목이 표시됩니다. 발신자 이메일과 이름을 입력하고 **메일 설정 저장**을 누릅니다. 저장만으로 메일이 발송되지는 않습니다.

- **SMTP**: 호스트 이름, 포트, 암호화 방식, 사용자명과 비밀번호를 입력합니다. 일반적인 STARTTLS는 587, SSL/TLS는 465이며 실제 서버 안내를 따르세요. 인증 정보를 사용하는 연결에는 암호화가 필수입니다. 암호화 없음은 인증 없는 신뢰된 릴레이 전용입니다. 사내 SMTP 서버도 관리자 설정으로 사용할 수 있습니다.
- **Mailgun**: 인증된 발신 도메인과 API 키를 입력합니다. 도메인의 리전에 따라 `api.mailgun.net`(미국) 또는 `api.eu.mailgun.net`(유럽)을 선택합니다. 임의의 API 주소는 허용하지 않습니다.
- **SES (Amazon)**: AWS API 액세스 키와 시크릿 키, 리전을 선택합니다. SES SMTP 비밀번호와 AWS API 키는 서로 다릅니다. 선택한 리전에서 발신자 이메일/도메인을 인증하고 해당 발신자에 대한 `ses:SendEmail` 최소 권한을 부여하세요. 샌드박스에서는 수신자도 인증해야 합니다. 임시 세션 자격 증명은 지원하지 않습니다.

비밀번호와 키는 `REPORT_SECRET_KEY`를 사용해 암호화하며 화면에 다시 표시하지 않습니다. 입력란을 비워 저장하면 기존 값을 유지하고 새 값을 입력하면 교체합니다. 메일러 변경 시 다른 메일러의 등록 정보도 유지합니다. SMTP 호스트·포트·암호화를 변경하면서 인증을 사용하는 경우 비밀번호를 다시 입력해야 합니다. 운영 서버의 암호화 키를 유지하고 안전하게 백업하세요.

## 테스트

먼저 설정을 저장하고 페이지 하단에 수신자 이메일 한 개를 입력한 뒤 **테스트 발송**을 누릅니다. 테스트는 저장된 설정으로만 발송되며 30초 간격으로 실행할 수 있습니다. 버튼은 발송 중 중복 클릭을 막습니다.

성공 메시지는 메일 서버가 발송 요청을 접수했다는 뜻입니다. 실제 도착은 받은 편지함과 스팸함에서 확인하세요. 실패하면 서버 주소, TLS 포트, 인증 정보, SES 권한/리전/샌드박스, Mailgun 도메인 인증, 수신자 제한과 서버의 외부 연결 상태를 확인하세요. 공급자 오류 본문이나 비밀 키는 화면에 노출하지 않습니다.

**서비스 주소 (인증 메일 링크)**를 지정하면 회원가입 및 관리자 선택 발송에 사용할 인증 링크를 생성합니다. 운영에서는 HTTPS 주소를 사용합니다. 주소가 비어 있고 `DJANGO_ALLOWED_HOSTS`에 명시적인 서비스 도메인이 하나만 있으면 HTTPS 주소를 자동으로 사용합니다. 도메인이 여러 개이거나 와일드카드인 경우 대표 주소를 직접 저장하세요. SMTP 테스트 성공은 인증 링크 주소의 설정 완료를 의미하지 않습니다. 인증 발송도 저장된 메일러와 발신자를 사용합니다. 자세한 절차는 [메일 인증 가이드](EMAIL_VERIFICATION.md)를 참고하세요.

## 업데이트 적용

```powershell
git pull
uv sync
uv run python manage.py migrate
```

`uv`를 사용하지 않는 환경에서는 동일한 Python 환경에 `python -m pip install -e .`로 의존성을 갱신한 뒤 `python manage.py migrate`를 실행하세요. 운영 정적 파일도 `python manage.py collectstatic --noinput`으로 갱신합니다. 추가된 마이그레이션은 메일 설정 테이블과 기본정보의 관리자 전용 메일 메뉴를 생성합니다.

참고: [Mailgun HTTP 발송](https://documentation.mailgun.com/docs/mailgun/user-manual/sending-messages/send-http), [Amazon SES SendEmail](https://docs.aws.amazon.com/boto3/latest/reference/services/sesv2/client/send_email.html).
