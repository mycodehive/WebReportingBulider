# 환경설정 API

로그인 사용자는 **환경설정 → API → 외부API**에서 자신의 LLM 연결을 관리합니다. 관리자도 다른 사용자의 연결을 이 화면에서 볼 수 없습니다.
기본정보·사이트관리·내부API는 기본적으로 관리자 전용입니다.
내부API에는 `실험실에 열심히 개발중이에요`를 표시합니다.

## 외부API · LLM 설정

1. **외부API**에서 연결명을 입력하고 제공자를 선택합니다. 공식 제공자를 선택하면 기본 주소가 자동 입력됩니다.
2. API 키를 입력하고 **모델 불러오기**를 누릅니다. 반환된 모델 목록에서 모델을 선택합니다.
3. **LLM 설정 등록**을 누르면 내 등록 목록에 나타납니다. 사용자마다 같은 연결명을 사용할 수 있고 여러 설정을 등록할 수 있습니다.
4. 목록의 **수정**에서 모델·주소·사용 여부를 변경합니다. API 키를 비우면 기존 키를 유지하며 모델 목록 조회에도 저장된 키를 사용합니다. 새 키를 입력하면 교체합니다. 키·제공자·주소 변경 시 모델을 다시 불러오세요.
5. **삭제**는 해당 설정과 암호화한 키를 함께 삭제합니다.

키는 기존 `REPORT_SECRET_KEY`로 암호화하고 화면에 다시 출력하지 않습니다. 운영 중 암호화 키를 변경하면 기존 키를 읽을 수 없으므로 백업·키 관리를 유지하세요.
모델 불러오기는 서버에서 제공자의 모델 목록 API를 호출합니다. 모델 목록에 나타나도 실제 생성 권한·과금·모델 지원 여부는 제공자의 정책에 따릅니다. 보고서 AI 생성이나 생성 API 호출은 수행하지 않습니다.
조회는 사용자마다 5초 간격이며, 페이지 수·응답 크기·모델 개수에 한도가 있습니다. 목록이 한도를 넘으면 일부만 반환하지 않고 오류를 표시합니다. 새 모델 선택 결과는 15분간 유효하며 만료 시 다시 불러옵니다. 저장한 모델을 유지하면서 연결명·사용 여부만 바꿀 때는 다시 조회할 필요가 없습니다.

관리자는 `/menu-management/`에서 탭과 하위 메뉴의 **관리자 전용** 체크박스를 관리합니다. 일반 사용자에게 열려면 상위 탭과 하위 메뉴 모두 체크를 해제해야 합니다. 외부API의 GET·등록·수정·삭제·모델 조회는 같은 정책을 적용하며 다른 사용자의 ID로 접근하면 404를 반환합니다. 회사로고·메뉴관리의 고유 관리자 권한은 유지합니다.
사용을 해제한 탭·외부API 메뉴는 일반 사용자에게 표시되지 않고 직접 접근도 차단합니다. 관리자에게는 관리·복구를 위한 직접 접근을 허용합니다.
기본 주소는 `/settings/api/internal/`, `/settings/api/external/`입니다.

## 적용

```powershell
git pull
uv run python manage.py migrate
uv run python manage.py runserver
```

마이그레이션 `0018`·`0019`를 적용하면 사용자별 설정, 메뉴 권한, 모델 조회 제한 테이블을 생성하고 API 탭·외부API 및 좌측 환경설정 메뉴를 일반 사용자에게 엽니다. 다른 탭·하위 메뉴는 관리자 전용으로 유지합니다.

기존 공용 LLM 설정은 관리자 계정이 정확히 하나일 때 그 계정에 이전합니다. 관리자가 여러 명이거나 없으면 소유자를 추측하지 않고 소유자 없는 암호화된 행을 보존하며 화면에는 표시하지 않습니다. 서버 운영자가 올바른 관리자 계정을 확인한 뒤 다음 명령으로 할당합니다. 이미 소유자가 있는 설정은 변경하지 않습니다.

```powershell
uv run python manage.py assign_legacy_llm --user-id 1
```

## 호환 API와 네트워크 보호

공식 제공자는 고정 기본 주소만 사용합니다. 프록시나 별도 제공자는 **OpenAI 호환 API**로 선택하며 서버 운영자가 허용한 호스트만 사용할 수 있습니다. 예를 들어 다음 환경 설정 후 서버를 재시작합니다.

```dotenv
REPORT_LLM_ALLOWED_HOSTS=llm.example.com,api.example.net
```

이 목록은 사용자 입력으로 변경할 수 없습니다. HTTPS 443, 공개 IP만 허용하며 DNS 결과를 검증한 IP에 TLS 연결을 고정합니다. 리디렉션·프록시 환경변수·사설/예약 IP는 사용하지 않습니다. API 키는 헤더로만 전송하고 URL·응답·선택 확인 토큰에 포함하지 않습니다. 제공자 오류 본문과 원시 예외도 사용자에게 출력하지 않습니다. 키를 비운 편집 화면에서는 저장된 키를 다른 제공자나 다른 주소로 전송하지 않습니다.

모델 조회는 로그인 세션과 CSRF 검사를 사용합니다. 브라우저에는 모델 ID·표시명과 사용자/제공자/주소/키에 바인딩된 서명 확인값만 반환합니다. 임의 모델 ID, 다른 사용자 확인값, 변조·만료된 확인값으로 새 설정을 저장할 수 없습니다.
