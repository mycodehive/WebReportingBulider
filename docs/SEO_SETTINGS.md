# SEO 설정

운영자(`is_staff=True`)는 **환경설정 → 기본정보 → SEO** 또는 `/settings/seo/`에서 설정을 등록·조회·수정·삭제합니다. 별도 SEO 설정을 Django admin에서 편집하는 기능은 제공하지 않습니다.

## 항목

- 사이트 제목·설명·키워드: 공개 소개페이지(`/intro`, `/intro/`)의 검색 메타 정보.
- 대표 서비스 주소: 경로 없는 HTTPS 주소. 예: `https://wrb.writeaday.click`. canonical과 Open Graph URL은 `/intro`로 통일합니다. 비우면 신뢰된 허용 도메인이 하나일 때만 자동으로 추론하고, 결정할 수 없으면 canonical을 생략합니다. 요청 Host로 만들지 않습니다.
- 공유 제목·설명: Open Graph와 Twitter 카드 정보. 비우면 사이트 제목·설명을 사용합니다.
- 공유 이미지: 방문자가 직접 열 수 있는 HTTPS 이미지 URL. 서버는 다운로드하지 않습니다. 인증 정보·서명·쿼리·프래그먼트 없는 공개 URL을 입력합니다.
- Google·네이버 인증 코드: 메타 태그의 `content` 값만 입력합니다. HTML 태그·스크립트는 넣지 않습니다.
- 소개페이지 검색 허용: 켜면 `index, follow`, 끄면 `noindex, nofollow`를 출력합니다.

설정이 없거나 제목·설명이 비어 있으면 기본 소개 제목·설명을 사용합니다. 검색 결과 미리보기는 배치 예시이며, 검색엔진의 실제 제목·설명·반영 시점이나 검색 순위를 보장하지 않습니다.

## 적용 범위와 권한

소개페이지 제목과 검색·공유 태그에 적용합니다. 기본 업무 레이아웃에는 메타 정보를 넣고 `noindex, nofollow`를 출력합니다. 업무 화면의 개별 제목은 유지합니다. Django admin·독립 보고서 출력 HTML 등 별도 레이아웃 전체에 적용하는 기능은 아닙니다.

공개 메타 정보는 방문자가 볼 수 있습니다. 인증 코드는 비밀번호나 API 키를 입력하는 항목이 아닙니다. SEO 설정 화면은 운영자만 볼 수 있으며 저장·삭제도 서버 권한 검사와 CSRF 보호를 적용합니다. 메뉴관리에서 SEO의 관리자 전용 표시를 해제해도 일반 사용자의 메뉴 노출과 직접 접근은 허용되지 않습니다.

## 삭제

삭제 동의 체크 후 **SEO 설정 삭제**를 누릅니다. 저장된 SEO 설정을 제거하고 기본 제목·설명으로 돌아갑니다. **소개페이지 검색 허용도 켜진 상태로 돌아갑니다.** 페이지 내용·보고서·사용자·메일 설정은 삭제하지 않습니다.

검색에서 제외하기 위해서는 설정을 삭제하는 대신 검색 허용을 끄고 저장하세요. `noindex`는 접근 권한 제어가 아니며 이미 수집한 결과의 제거 시점은 검색엔진이 결정합니다.

## 배포

```bash
git pull origin main
uv sync --frozen
uv run python manage.py migrate
uv run python manage.py collectstatic --noinput
```

애플리케이션 서비스를 재시작합니다. `0022_seo_configuration`은 SEO 테이블과 기본정보 탭의 운영자 전용 SEO 메뉴를 추가합니다. 기존 설정을 일괄 덮어쓰지 않습니다. 이후 SEO 값 변경은 저장만으로 반영되며 서비스 재시작은 필요하지 않습니다.
